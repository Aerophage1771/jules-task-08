Family 1 — Structure

Central Contrast Theme

Role vs. Main Point

Identifying the building blocks of an argument without evaluating its validity.

Main Conclusion

The Task
Identify the primary claim the author is trying to prove.
Key Contrast
Focuses on the entire argument's ultimate endpoint.
Stem Example
"Which one of the following most accurately expresses the main conclusion of the argument?"
The Method
Find the conclusion. Apply the 'Why Test' (does it support something else, or is it supported?). Watch out for intermediate conclusion traps.

Argument Part

The Task
Identify the function of a specific phrase within the argument.
Key Contrast
Focuses on the structural role of a single specific piece, not the overall point.
Stem Example
"The claim that [X] plays which one of the following roles in the argument?"
The Method
Locate the phrase. Ask: 'Does it support something?' and 'Is it supported by something?' Determine content vs. function.

Family 2 — Patterns & Flaws

Central Contrast Theme

Description vs. Replication vs. Error

Analyzing how an argument is built and where its reasoning breaks down.

Method of Reasoning

The Task
Describe the argumentative strategy used.
Key Contrast
Pure description of valid or invalid logic.
Stem Example
"The argument proceeds by..."
The Method
Abstract the argument's structure. Match the description in the choices to the stimulus.

Flaw

The Task
Identify why the reasoning is structurally invalid.
Key Contrast
Describes an error in logic.
Stem Example
"The reasoning in the argument is most vulnerable to criticism on the grounds that..."
The Method
Play Devil's Advocate. Ask 'How could the evidence be true while the conclusion is still wrong?' Identify the logical gap.

Parallel Reasoning

The Task
Find an argument with the identical logical structure.
Key Contrast
Replicates valid logic.
Stem Example
"Which one of the following exhibits a pattern of reasoning most similar to that in the argument above?"
The Method
Identify the conclusion's force and scope. Match the premises' structure. Verify the logical flow matches exactly.

Parallel Flaw

The Task
Find an argument with the identical structural error.
Key Contrast
Replicates an error in logic.
Stem Example
"The flawed pattern of reasoning in the argument above is most similar to that in which one of the following?"
The Method
Identify the specific flaw. Find the choice that commits the exact same logical sin.

Family 3 — Argument Impact & Assumptions

Central Contrast Theme

Bridging vs. Breaking vs. Needing

Interacting with the logical gap between premises and conclusion.

Strengthen

The Task
Make the conclusion more likely to be true.
Key Contrast
Helps the argument, doesn't need to prove it 100%.
Stem Example
"Which one of the following, if true, most strengthens the argument?"
The Method
Identify the gap. Find a new fact that helps bridge the gap or rules out an alternate cause.

Weaken

The Task
Make the conclusion less likely to be true.
Key Contrast
Hurts the argument, doesn't need to destroy it entirely.
Stem Example
"Which one of the following, if true, most seriously weakens the argument?"
The Method
Identify the gap. Find a new fact that widens the gap, introduces an alternate cause, or attacks the assumption.

Evaluate

The Task
Identify a question whose answer would test the argument's validity.
Key Contrast
Tests the gap's vulnerability.
Stem Example
"The answer to which one of the following questions would be most useful to know in evaluating the argument?"
The Method
Apply the Variance Test: Supply polar opposite answers (e.g., yes/no, high/low) to the choice and see if it both strengthens and weakens.

Sufficient Assum.

The Task
Provide a premise that fully guarantees the conclusion.
Key Contrast
Must guarantee the conclusion (100% proof).
Stem Example
"The conclusion follows logically if which one of the following is assumed?"
The Method
Identify New/Dangling Terms. Look for an Entry, Middle, or End Gap. Insert the answer and rerun the chain.

Necessary Assum.

The Task
Identify a premise the argument requires to survive.
Key Contrast
Required by the conclusion, but doesn't have to prove it.
Stem Example
"Which one of the following is an assumption on which the argument depends?"
The Method
Look for gaps. Apply the Negation Test: logically negate the choice. If the negated choice destroys the argument, it's correct.

Family 4 — Principles

Central Contrast Theme

Creating Rules vs. Following Rules

Working with general rules applied to specific situations.

Principle Strengthen

The Task
Find a general rule that helps justify the specific reasoning.
Key Contrast
Moves from specific gap to general rule.
Stem Example
"Which one of the following principles, if valid, most helps to justify the reasoning?"
The Method
Identify the gap. Find a broad rule that connects the premises to the conclusion.

Principle Apply

The Task
Apply a given rule to a new specific situation.
Key Contrast
Moves from general rule to specific application.
Stem Example
"Which one of the following judgments conforms most closely to the principle cited above?"
The Method
Convert the rule to a strict checklist. A choice must meet all sufficient conditions or fail a necessary one.

Principle Generalize

The Task
Extract a general rule from a specific situation.
Key Contrast
Moves from specific case to general rule.
Stem Example
"The situation described above most closely conforms to which one of the following generalizations?"
The Method
Identify the underlying logic or moral of the specific case. Find the abstract rule that matches.

Family 5 — Inference

Central Contrast Theme

Absolute Truth vs. Strong Support

Deriving conclusions based purely on the provided facts.

Must Be True

The Task
Identify a statement that is 100% guaranteed by the stimulus.
Key Contrast
Requires absolute certainty.
Stem Example
"If the statements above are true, which one of the following must also be true?"
The Method
Combine facts strictly. Ask 'Could this possibly be false?' Avoid outside information.

Most Strongly Supp.

The Task
Identify a statement highly likely to be true based on the stimulus.
Key Contrast
Allows a tiny margin of doubt compared to MBT.
Stem Example
"The statements above, if true, most strongly support which one of the following?"
The Method
Synthesize the facts. Find a safe, reasonable conclusion. Doesn't need formal 100% proof, just 99% safety.

Must Be False

The Task
Identify a statement that absolutely contradicts the stimulus.
Key Contrast
Requires absolute contradiction.
Stem Example
"If the statements above are true, which one of the following must be false?"
The Method
Apply the Coexistence Test: can this choice exist in the same universe as the stimulus? If no, it's correct.

Fill in the Blank

The Task
Complete the logical thought at the end of the stimulus.
Key Contrast
Contextual inference based on flow.
Stem Example
"Which one of the following most logically completes the argument? ... ______."
The Method
Read for the direction of the argument. Predict the logical endpoint based on the immediately preceding sentences.

Family 6 — Paradox / Explain

Central Contrast Theme

Bridging the Unexpected

Resolving apparent contradictions or explaining surprising facts.

Paradox / Explain

The Task
Find a fact that allows two seemingly contradictory statements to both be true.
Key Contrast
Focuses on resolving mystery, not arguing.
Stem Example
"Which one of the following, if true, does most to resolve the apparent discrepancy?"
The Method
Preserve both facts. Find the hidden distinction or bridge that explains how they coexist peacefully.

Family 7 — Dialogue

Central Contrast Theme

Point of Contention vs. Common Ground

Analyzing interactions between two speakers.

Disagree

The Task
Identify the exact statement both speakers have an opinion on, and disagree about.
Key Contrast
Focuses on explicit conflict.
Stem Example
"The dialogue provides the most support for the claim that X and Y disagree over whether..."
The Method
Apply the Speaker-by-Speaker Commitment Test. Speaker 1 must say yes/no, and Speaker 2 must say the exact opposite.

Agree

The Task
Identify a statement both speakers would endorse.
Key Contrast
Focuses on shared assumptions or explicit agreement.
Stem Example
"The dialogue provides the most support for the claim that X and Y agree that..."
The Method
Apply the Speaker-by-Speaker Commitment Test. Both speakers must be committed to the exact same position.
